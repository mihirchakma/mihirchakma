### What SisuSpace Includes

- Secure authentication using HttpOnly JWT cookies
- Role-based access for students, contributors, guests, and administrators
- Educational resource uploading, searching, filtering, rating, and bookmarking
- Administrative moderation and abuse-reporting workflows
- Peer-supported questions, answers, resource requests, and notifications
- Contributor points, leaderboards, and trusted-user features
- Responsive React interface with a Django REST Framework backend
- Automated backend tests and continuous integration

### Core Technology

`React` · `Vite` · `Tailwind CSS` · `Django` · `Django REST Framework`
